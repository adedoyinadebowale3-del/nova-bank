Nova Bank 💜

A modern banking website frontend built with HTML and CSS as part of my Software Engineering academic project.

About the Project

Nova Bank is a frontend demonstration project inspired by modern digital banking platforms. It focuses on presenting a clean, professional interface with a purple-themed design.

The project is being developed to practise frontend development skills and explore how banking websites organise and present information to users.

Technologies Used

- CSS3
- JavaScript
